# Earlier development prompts

For the final TT-100 comparison, use the [final protocol archive](../../experiments/tt100-final/protocol/README.md). The files below are earlier development records and do not define that comparison.

These are three archived task instructions from the paper's development runs,
not newly designed examples or a full model/system transcript. Only assigned
input and output paths have been replaced with placeholders. See SOURCES.md
for provenance and unavailable historical records.

Both agent conditions used Codex 5.6 through the same interface and workflow.
The domain Skill access condition differs. Historical Skill versions and
complete runtime context are not reconstructed by this software release.
The archive requested timing/usage evidence, but not all requested fields were
retained. These files do not establish a frozen matched-budget evaluation.
