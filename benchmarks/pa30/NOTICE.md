# PA-30 third-party data notice

`inputs/test01/top_primitive.v` through `inputs/test30/top_primitive.v` are
original benchmarks from **Problem A: Learning Arithmetic Operations from
Gate-Level Circuit**, ICCAD 2022 CAD Contest. The official contest page
identifies Cadence Design Systems, Inc. as the Problem A provider.

- Official problem page: <https://www.iccad-contest.org/2022/Problems.html>
- Official final benchmark archive: <https://drive.google.com/file/d/1axlAw1rPXbTb_kYsvbwKshcEMF37SQWz/view>
- Archive and file identities: [source.json](source.json).

The 30 included files preserve the original bytes and match the frozen
experiment input hashes. No contest reference answers are included.

The upstream files are publicly downloadable, but an explicit redistribution
license has not been identified. The RTLREX project does not claim ownership
of these files or grant an MIT license for them. Public redistribution terms
